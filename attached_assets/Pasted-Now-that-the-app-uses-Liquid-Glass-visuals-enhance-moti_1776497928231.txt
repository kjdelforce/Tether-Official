Constraints:
- Keep all interactions subtle and performant.
- Respect prefers-reduced-motion and prefers-reduced-transparency.

- For .lg-surface-primary and .lg-surface-secondary:
  - Add a soft specular highlight band using ::before, aligned to the top edge, with a white-to-transparent gradient and very low opacity.

- Define a shared interaction pattern for all tappable glass elements (cards, pills, prominent buttons):

- Ensure this pattern is opt-in via a class like .lg-interactive so non-interactive surfaces stay static.

3. Parallax & floating behavior
- For the bottom dock and any floating header bars:
  - add a tiny parallax motion tied to cursor movement (desktop only) using a small JS utility:

    - updates transform: translate3d by max ±3px,

  - wrap this in a prefers-reduced-motion check and disable if the user has it enabled.

- Implement @media (prefers-reduced-motion: reduce) and (prefers-reduced-transparency: reduce):

  - replace glass with darker, more opaque solids while keeping the same shapes and layout.
- Ensure focus states for keyboard users are clearly visible over glass (e.g. bright outline or glow).
